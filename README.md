# Aura Luz Arévalo · Asesora de EPS

Landing page informativa y comercial para orientación independiente sobre trámites relacionados con EPS en Colombia.

## Ejecutar localmente

La página no requiere dependencias ni compilación. Abre `index.html` directamente en un navegador o usa la extensión **Live Server** de Visual Studio Code y selecciona **Go Live**.

## Publicar más adelante

Sube `index.html`, `styles.css`, `script.js` y la carpeta `assets/` (si se agregan recursos) a cualquier servicio de alojamiento estático, como GitHub Pages, Netlify o el hosting de tu preferencia.
